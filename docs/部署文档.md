# 麒麟安全运维系统 — 部署文档

## 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | 麒麟 Linux V10+ (loongarch64 / x86_64 / aarch64) |
| Go | 1.21+ (编译时使用) |
| 内存 | >= 2GB |
| 磁盘 | >= 1GB 可用 |
| 权限 | root (systemd 服务) |
| 网络 | 可访问 DeepSeek API (`api.deepseek.com`) |

## 目录结构

```
/opt/safe-agent/
├── admin                 # 管理后台二进制
├── agent                 # Agent 采集器二进制
├── env                   # 环境变量 (LLM_API_KEY 等)
├── data/
│   └── agent.db          # SQLite 数据库
├── frontend/
│   └── dist/             # 前端 Web 页面
│       ├── index.html
│       └── assets/
└── simulate_attack.sh    # 攻击模拟脚本
```

## 一键部署

### 1. 克隆项目

```bash
git clone https://github.com/mudjjja/safe-agent.git
cd safe-agent
```

### 2. 设置 API Key

```bash
export LLM_API_KEY="sk-your-deepseek-api-key"
```

### 3. 执行部署

```bash
sudo -E bash deploy/deploy.sh
```

脚本会自动完成：编译 → 创建目录 → 复制文件 → 配置环境 → 安装 systemd 服务 → 启动 → 验证。

### 4. 验证

```bash
# 检查服务状态
systemctl status kylin-admin kylin-agent

# 测试 API
curl http://localhost:8080/api/dashboard/stats

# 查看 Agent 在线状态
curl -s http://localhost:8080/api/agent/list | python3 -m json.tool
```

## 手动部署

如果自动部署脚本不适用，按以下步骤手动部署：

### 1. 编译

```bash
# 麒麟 loongarch64 架构直接编译
go build -o build/admin ./cmd/admin/
go build -o build/agent ./cmd/agent/

# 如遇依赖问题
# go get modernc.org/libc@latest && go get modernc.org/sqlite@latest && go mod tidy
```

### 2. 创建目录并复制文件

```bash
sudo mkdir -p /opt/safe-agent/{data,frontend/dist}
sudo cp build/admin /opt/safe-agent/admin
sudo cp build/agent /opt/safe-agent/agent
sudo cp -r frontend/dist/* /opt/safe-agent/frontend/dist/
sudo chmod +x /opt/safe-agent/admin /opt/safe-agent/agent
```

### 3. 配置环境变量

```bash
sudo tee /opt/safe-agent/env > /dev/null << EOF
LLM_API_KEY=sk-your-api-key
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
EOF
sudo chmod 600 /opt/safe-agent/env
```

### 4. 安装 systemd 服务

```bash
sudo cp deploy/kylin-admin.service /etc/systemd/system/
sudo cp deploy/kylin-agent.service /etc/systemd/system/
sudo systemctl daemon-reload
```

### 5. 启动服务

```bash
sudo systemctl enable --now kylin-admin
sudo systemctl enable --now kylin-agent
```

## 服务管理

```bash
# 查看状态
systemctl status kylin-admin kylin-agent

# 重启
systemctl restart kylin-admin kylin-agent

# 查看日志
journalctl -u kylin-admin -f    # admin 实时日志
journalctl -u kylin-agent -f    # agent 实时日志
tail -f /var/log/kylin-agent.log  # agent 文件日志

# 停止
systemctl stop kylin-admin kylin-agent

# 禁用开机自启
systemctl disable kylin-admin kylin-agent
```

## Agent 配置

修改 `/opt/safe-agent/env` 或直接修改 service 文件：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `AGENT_ID` | kylin-agent-01 | Agent 唯一标识 |
| `ADMIN_URL` | http://127.0.0.1:8080 | Admin 后端地址 |
| `LOG_DIR` | /var/log | Agent 日志目录 |

## 多 Agent 部署

如需在多台机器部署 Agent，每台机器上：

```bash
# 仅编译 agent
go build -o build/agent ./cmd/agent/

# 复制 agent 二进制和 service
sudo cp build/agent /opt/safe-agent/agent
sudo cp deploy/kylin-agent.service /etc/systemd/system/kylin-agent.service

# 修改 AGENT_ID 和 ADMIN_URL
sudo sed -i 's/AGENT_ID=kylin-agent-01/AGENT_ID=kylin-agent-02/' /etc/systemd/system/kylin-agent.service
sudo sed -i 's|ADMIN_URL=http://127.0.0.1:8080|ADMIN_URL=http://<admin-ip>:8080|' /etc/systemd/system/kylin-agent.service

sudo systemctl daemon-reload
sudo systemctl enable --now kylin-agent
```

## 故障排查

### 服务启动失败

```bash
# 查看详细错误
journalctl -u kylin-admin -n 50 --no-pager
journalctl -u kylin-agent -n 50 --no-pager

# 检查二进制是否正常
/opt/safe-agent/admin --help 2>&1    # Go 不支持 --help，但可检查依赖库
ldd /opt/safe-agent/admin            # 检查动态链接
```

### API 无响应

```bash
# 检查端口监听
ss -tlnp | grep 8080

# 检查防火墙
firewall-cmd --list-ports
# 如需开放端口
firewall-cmd --add-port=8080/tcp --permanent && firewall-cmd --reload
```

### Agent 离线

```bash
# Agent 是否在运行
systemctl is-active kylin-agent

# 手动运行 agent 看报错
/opt/safe-agent/agent

# 检查 ADMIN_URL 连通性
curl -s http://localhost:8080/api/agent/heartbeat
```

### 数据库问题

```bash
# 备份数据库
cp /opt/safe-agent/data/agent.db /opt/safe-agent/data/agent.db.bak

# 重置数据库（会丢失所有数据）
systemctl stop kylin-admin
rm /opt/safe-agent/data/agent.db
systemctl start kylin-admin  # 启动时自动创建新库
```

### SQLite 写入慢

如果指标插入超过 500ms，修改为 WAL 模式：

```bash
sqlite3 /opt/safe-agent/data/agent.db "PRAGMA journal_mode=WAL;"
```

或在代码中 `gorm.Open` 时添加参数：`sqlite.Open(cfg.DBPath + "?_journal_mode=WAL")`
